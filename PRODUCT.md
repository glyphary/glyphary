# Product

## Register

product

## Users

Glyphary is for people who keep large local Markdown or Obsidian-style vaults and want a desktop editor that feels polished without giving up plain files. They are usually writing, researching, organizing notes, editing canvases, managing tasks, or browsing linked local knowledge.

## Product Purpose

Glyphary provides a local-first Markdown workspace with rich visual editing, Obsidian-compatible vault structures, fast search, canvas support, base views, themes, plugins, and native desktop conveniences. Success means users can work naturally in their notes while every file remains portable Markdown or compatible local data.

## Brand Personality

Quiet, capable, precise. The app should feel like a serious desktop tool: calm enough for long writing sessions, dense enough for large vaults, and refined enough that details do not distract from the work.

## Anti-references

Avoid marketing-page composition inside the app, decorative dashboards, generic AI SaaS chrome, heavy gradients, ornamental glass, oversized rounded cards, and invented controls where native desktop patterns already exist. The product should not feel like a web app pretending to be premium.

## Design Principles

- Keep local files and vault compatibility central to every workflow.
- Prefer native-feeling controls, menus, motion, and window behavior where they make the app easier to trust.
- Make rich Markdown editing feel direct while preserving readable source files.
- Keep navigation fast for large vaults: drawers, search, recent files, starred files, and switchers should support repeated daily use.
- Let polish show through small details rather than decorative surfaces.

## Accessibility & Inclusion

Target practical desktop accessibility: keyboard-accessible controls, readable contrast in light and dark themes, reduced-motion support, clear focus states, and no feature that depends only on color or decorative motion.
